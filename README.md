Create a folder named server.
Inside it, run npm init -y and npm install express cors.
Create a file named index.js and paste the code attached as index.js

Go back to your main folder.
Run: npx create-react-app client
Go into the client folder: cd client
Replace src/App.js with the code attached as App.js

Replace src/App.css with the code attached as App.css

run cd server
run node index.js

Click the + button in your terminal window to open a second terminal, now,
run cd client
run npm start
